# 🛵 منصة توصيل

منصة توصيل طلبات جوه المحافظة: مطاعم، وصيدليات، وبقالة، وبعدين مشاوير بين الناس.
كل شركة مشتركة ليها بياناتها المعزولة تماماً عن غيرها.

> 📖 الملف ده مكتوب بلغة بسيطة. الجزء الأخير منه للمبرمجين.

---

## 🧭 النظام فيه إيه دلوقتي (النسخة الأولى)

| الدور           | يقدر يعمل إيه                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| 🛍️ العميل       | يتفرج على المحلات، يملا السلة، يعمل حساب بموبايله وكلمة سر، يطلب، يتابع طلبه لحظة بلحظة، يلغي، يقيّم   |
| 🏪 المحل        | يستقبل الطلبات بتنبيه، يقبل أو يرفض بسبب، يعلن إن الطلب جاهز، يعدّل أسعاره، يفتح ويقفل                 |
| 🛵 الطيار       | يبدأ ويقفل شغله، يشوف طلباته، يستلم، يسلّم ويسجل المبلغ اللي حصّله، يشوف عهدته                         |
| 📋 مدير التشغيل | يشوف كل الطلبات، يوزعها على الطيارين، يلغي، يعمل التسوية اليومية، يحسم فروقات التحصيل                  |
| ⚙️ مدير الشركة  | كل اللي فوق + المناطق وأسعارها، المحلات وعمولاتها، حسابات الموظفين، سجل العمليات                       |
| 👑 مالك المنصة  | يضيف شركة بضغطة زرار، يحدد باقتها، يسجل مدفوعات الاشتراك، يوقف أو يشغّل أي شركة، يشوف أرقام كل الشركات |

## 🚀 تشغيل النظام على جهازك للتجربة

### المطلوب مرة واحدة

1. **Node.js نسخة 22** من [nodejs.org](https://nodejs.org)
2. **Docker Desktop** من [docker.com](https://www.docker.com/products/docker-desktop)
3. افتح الترمينال واكتب: `corepack enable`

### التشغيل

افتح الترمينال في فولدر المشروع واكتب الأوامر دي بالترتيب:

```bash
pnpm setup          # تنزيل المكتبات + عمل ملف الإعدادات بمفاتيح آمنة
pnpm db:up          # تشغيل قاعدة البيانات
pnpm db:migrate     # بناء الجداول وحيطان الأمان
pnpm db:seed        # البيانات التجريبية
pnpm dev            # تشغيل السيرفر والواجهات
```

بعدها افتح المتصفح على: **http://localhost:5173** 🎉

> 💡 عشان تشوفه كأنه موبايل: في كروم اضغط `F12` وبعدين أيقونة الموبايل.

### 🧪 الحسابات التجريبية

في شركتين تجريبيتين منفصلتين. اختار الشركة من أعلى صفحة الدخول.
**كلمة السر لكل الحسابات:** `Demo@123456`

| الدور             | بني سويف             | الفيوم               |
| ----------------- | -------------------- | -------------------- |
| ⚙️ مدير الشركة    | `01000000001`        | `01100000001`        |
| 📋 مدير التشغيل   | `01000000002`        | `01100000002`        |
| 🏪 مطعم           | `01000000011`        | `01100000011`        |
| 🏪 صيدلية         | `01000000012`        | `01100000012`        |
| 🏪 سوبر ماركت     | `01000000013`        | `01100000013`        |
| 🛵 طيار ١ / ٢ / ٣ | `01000000021` → `23` | `01100000021` → `23` |
| 🛍️ عميل           | `01000000031` / `32` | `01100000031` / `32` |

العميل الجديد يقدر يعمل حساب بنفسه من "حساب جديد" في صفحة الدخول.

**👑 لوحة مالك المنصة:** افتح `http://localhost:5173/platform`
الإيميل `owner@demo.local` وكلمة السر `Demo@123456`.
أول دخول هيعرض مربع (QR): صوّره بتطبيق **Google Authenticator** على موبايلك، واكتب الكود اللي ظهر. بعد كده كل دخول هيطلب الكود ده.

### 🎬 جرّب الرحلة كاملة (افتح كل دور في نافذة متصفح منفصلة)

1. 🛍️ **العميل** (`01000000031`): اختار "مشويات أبو علي"، ضيف منتجات، اعرض السلة، ادخل، أكّد الطلب.
2. 🏪 **المطعم** (`01000000011`): هيظهر الطلب فوراً ← قبول ← "الطلب جاهز".
3. 📋 **مدير التشغيل** (`01000000002`): اختار الطيار "محمود الطيار" من القائمة جنب الطلب.
4. 🛵 **الطيار** (`01000000021`): "استلمت الطلب" ← "سلّمت الطلب" ← اكتب المبلغ ← تأكيد.
5. 🛍️ **العميل:** هيشوف إن الطلب اتسلّم ويقيّم.
6. 📋 **مدير التشغيل:** صفحة "الطيارين" ← استلم العهدة من الطيار. صفحة "الفلوس" هتلاقي حق المحل بعد العمولة.
7. ⚙️ **مدير الشركة** (`01000000001`): "الإدارة" ← "سجل العمليات" هتلاقي كل اللي حصل بالتفصيل.

🧱 **جرّب العزل:** ادخل بمدير تشغيل الفيوم (`01100000002`)، مش هتشوف ولا طلب من بني سويف.

## 🌍 رفع النظام على الإنترنت

### ١) هتحتاج

- **سيرفر لينكس** (Ubuntu 24) بـ ٢ جيجا رام على الأقل. تقدر تشتريه من Hetzner أو DigitalOcean أو Contabo، وسعره حوالي ٥ لـ ١٠ دولار في الشهر.
- **اسم دومين** (مثلاً `tawseel.com`)، وكل شركة يبقى ليها عنوان فرعي منه (`beni-suef.tawseel.com`)، ولوحتك إنت على `admin.tawseel.com`.

### ٢) وجّه العناوين للسيرفر

من لوحة الدومين، اعمل سجل `A` واحد بس: الاسم `*` (يعني كل العناوين الفرعية) يشاور على رقم IP السيرفر.
كده أي شركة جديدة تضيفها من لوحتك تشتغل على عنوانها فوراً، وشهادة الأمان بتطلع لوحدها.

### ٣) جهّز السيرفر (مرة واحدة)

```bash
# تثبيت Docker
curl -fsSL https://get.docker.com | sh

# قفل كل المنافذ ما عدا الدخول للسيرفر والموقع
ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw enable

# تنزيل المشروع
git clone <رابط المستودع> delivery && cd delivery
```

### ٤) الإعدادات والأسرار

```bash
cp .env.production.example .env
nano .env
```

غيّر كل `CHANGE_ME` لقيمة عشوائية بالأمر `openssl rand -hex 32`، واكتب الدومين في `BASE_DOMAIN`، وعنوان لوحتك في `PLATFORM_HOST`، وإيميلك في `ACME_EMAIL`.

> ⚠️ **احفظ `BACKUP_PASSPHRASE` في مكان آمن بره السيرفر** (زي مدير كلمات سر). من غيرها النسخ الاحتياطية مش هتتفتح.

### ٥) التشغيل

```bash
docker compose up -d --build
```

النظام هيعمل شهادة الأمان (HTTPS) لوحده، والنسخ الاحتياطي هيشتغل لوحده كل يوم الساعة ٣ الفجر.

### ٦) اعمل حسابك كمالك للمنصة (مرة واحدة)

```bash
docker compose run --rm migrate node dist/db/create-platform-admin.js --email you@example.com --name "اسمك"
```

كلمة السر هتظهر **مرة واحدة بس**. افتح `https://admin.الدومين/platform`، وادخل، وسجّل تطبيق الكود على موبايلك.

### ٧) ضيف الشركات من لوحتك

من **الشركات ← شركة جديدة**: اكتب اسمها وعنوانها المختصر (مثلاً `beni-suef`) وباقتها وموبايل مديرها.
بيانات دخول المدير هتظهر مرة واحدة: ابعتها له، وهو يضيف المناطق والمحلات والطيارين.

- **الاشتراكات:** سجّل كل دفعة من صفحة الشركة، والاشتراك بيتمد لوحده.
- **المتأخرين:** بعد انتهاء الاشتراك بـ `SUBSCRIPTION_GRACE_DAYS` يوم (افتراضي ٣) الشركة بتتوقف لوحدها، وأول ما تسجل دفعتها بترجع تشتغل.
- **الباقات:** بتحدد سعر الشهر وأقصى عدد محلات وطيارين، والنظام بيمنع الشركة تعدّي حدود باقتها.

### 🔄 التحديث لنسخة جديدة

```bash
git pull && docker compose up -d --build
```

### 💾 النسخ الاحتياطي

- بيتعمل **تلقائي كل يوم** في فولدر `backups/`، متشفّر، وبيتمسح القديم بعد ١٤ يوم.
- **مهم جداً:** انسخ فولدر `backups/` لمكان تاني بره السيرفر بشكل دوري (مثلاً Google Drive أو Backblaze)، عشان لو السيرفر نفسه باظ.
- نسخة يدوية دلوقتي: `docker compose exec backup bash /scripts/backup.sh`
- استرجاع نسخة: `docker compose exec backup bash /scripts/restore.sh /backups/<اسم الملف>`

## 👨‍💻 للمبرمجين

### الأدوات

| الجزء           | الأداة                                                                     |
| --------------- | -------------------------------------------------------------------------- |
| اللغة           | TypeScript في كل المشروع                                                   |
| السيرفر         | NestJS 11 + Drizzle ORM                                                    |
| قاعدة البيانات  | PostgreSQL 16 (+ PostGIS للخرايط في المرحلة التانية) مع Row-Level Security |
| الذاكرة السريعة | Redis (أكواد التحقق، حدود المحاولات)                                       |
| اللحظي          | Socket.IO                                                                  |
| الواجهات        | React 19 + Vite + Tailwind 4، كتطبيق ويب يتثبت (PWA)                       |
| الاختبارات      | Vitest + Supertest على قاعدة بيانات حقيقية                                 |
| الرفع           | Docker Compose + Caddy (HTTPS تلقائي)                                      |

### التقسيم

```
apps/
  api/                  السيرفر
    src/common/         البوّاب، قاعدة البيانات، التشفير، سجل العمليات، حدود المحاولات
    src/modules/        auth · orders · finance · catalog · customers · drivers · admin · realtime
    src/db/             شكل الجداول، الترحيلات، البيانات التجريبية، إضافة شركة أو مالك منصة
    src/modules/platform/  لوحة مالك المنصة (حساب قاعدة بيانات منفصل، ودخول بكود من الموبايل)
    drizzle/            ترحيلات SQL (منها 0001_security.sql: العزل والحماية جوه القاعدة)
    test/               اختبارات التكامل: الفلوس، الصلاحيات، العزل، الدخول
  web/                  الواجهات (كل دور بيتحمّل لوحده)
packages/
  shared/               قواعد فحص المدخلات، دورة الطلب، حسابات الفلوس (مشتركة بين الاتنين)
deploy/                 إعدادات Caddy
scripts/                النسخ الاحتياطي والاسترجاع
```

### قواعد مهمة

- **كل استعلام على بيانات شركة لازم يعدّي من `DbService.withTenant()`**. قاعدة البيانات نفسها بتخفي أي صف مش تبع الشركة الحالية.
- **الفلوس بالقرش** كأرقام صحيحة، وأي حركة فلوس بتتسجل بقيد مزدوج عن طريق `LedgerService.post()`. جداول القيود وسجل العمليات ممنوع تعديلها أو مسحها (مفروض جوه قاعدة البيانات).
- **أي مسار في السيرفر مقفول افتراضياً**، ولازم يتحدد له `@Roles(...)` أو `@Public()`.
- **لوحة مالك المنصة** ليها حساب قاعدة بيانات منفصل (`PLATFORM_DATABASE_URL`): بيدير الشركات والباقات، ومايقدرش يقرا طلبات أو فلوس أو عملاء أي شركة. وحساب السيرفر العادي ممنوع من جداول المنصة خالص.
- **أي مدخل** بيتفحص بقواعد `zod` من `@dm/shared/schemas`، وأي حقل زيادة بيترفض.
- الأسعار دايماً بتتحسب في السيرفر من قاعدة البيانات، ومابتتاخدش من الموبايل أبداً.

### أوامر مفيدة

```bash
pnpm test                       # كل الاختبارات (محتاج قاعدة بيانات delivery_test)
pnpm typecheck                  # فحص الأنواع
pnpm audit:deps                 # فحص المكتبات من الثغرات
pnpm --filter @dm/api db:generate   # ترحيل جديد بعد تعديل src/db/schema.ts
```

للاختبارات: اعمل قاعدة `delivery_test` مرة واحدة بـ `pnpm db:test:create`، والإعدادات الافتراضية في `apps/api/vitest.config.ts`، ويتغيروا بـ `TEST_DATABASE_URL` و `TEST_MIGRATION_DATABASE_URL` و `TEST_REDIS_URL`.
